# Hedgefire

Hedgefire is a free mod for **Company of Heroes: Tales of Valor** by AlynGame, the games branch
of AlynGo Ltd. ([alyngo.com](https://alyngo.com)). It comes with its own launcher, which installs
the mod into your game and keeps it up to date.

This repository holds the releases only: the installer and the update packages.

## What you need

- Company of Heroes: Tales of Valor **version 2.602**, already installed (not the Steam edition).
- Windows 10 or 11.

## Install

1. Open the [latest release](https://github.com/AlynGo-Org/Hedgefire-Releases/releases/latest)
   and download `AlynGame.Hedgefire-win-Setup.exe`.
2. Run it. The installer is not signed, so Windows may show "Windows protected your PC": click
   **More info**, then **Run anyway**.
3. The launcher opens and looks for your game. If it cannot find it, click **Choose folder** and
   pick the folder that holds `RelicCOH.exe`.
4. Click **Play**. The launcher installs the mod files into the game folder and starts the game.

## Updates

The launcher checks for updates each time it starts. When one is available, the bottom bar shows
it with an **Update** button; Play keeps working with the version you have until you update.

## Uninstall

Remove **Hedgefire** in Windows Settings, Apps. The mod files stay in the game folder (the
`Hedgefire` folder and the five `Hedgefire*.module` files); delete them to remove the mod
completely.
